FLIGHT DELAY ANALYSIS · DUCKDB / SQL / PYTHON

HOSPITAL READMISSION · DUCKDB / SQL / PYTHON

Who comes back within 30 days?

8.98% of 69,985 patients readmitted <30 days

Risk rises with complexity: 3+ prior inpatient visits readmitted at 26.5% vs 8.1% with none (OR 3.82); 9 diagnoses 12.3% vs 8.3% for 3; 17+ medications 13.7% vs 7.3% for 1–4. Logistic regression: 63% accuracy.
